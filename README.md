# 一日食记 · Daily Bites

一个轻量、开源的中文饮食记录网页。好好吃饭，慢慢记录。

## 功能

- 按日期记录早餐、午餐、晚餐和加餐，支持编辑与删除。
- 填写食物、份量、可选的估算热量及备注。
- 查看每日记录数、不同食物名称数与已填写的热量总和。
- 浏览器 localStorage 保存，刷新后保留；支持全部记录导出为 JSON。
- 适配电脑与手机，原生 HTML、CSS、JavaScript，无第三方运行依赖。

## 本地运行

需要 Python 3；npm 快捷命令和测试还需要 Node.js 18 或更高版本。

```sh
npm start
```

在本地电脑运行时，访问 `http://localhost:3000`。也可以直接运行 `python3 -m http.server 3000`，无需安装 npm 依赖。服务器只提供静态文件，不接收饮食数据。部署时将 `index.html`、`style.css`、`app.js` 和 `records.js` 放到任意静态网站托管平台；正式部署使用 HTTPS。

## 验证

```sh
npm test
```

自动测试覆盖数据校验、日期和统计逻辑。手动检查：新增记录、编辑、刷新确认保留、切换日期、导出 JSON、删除记录确认统计更新。

## 数据与隐私

记录仅保存在当前浏览器、当前站点下，无账号或跨设备同步。清除网站数据、更换浏览器或网站地址会导致原记录不可见，请定期导出备份。当前版本支持导出，暂不支持导入。共享设备上的其他使用者可能看到记录。

热量由使用者填写；空值不计入总和，显示总量可能不完整，仅供记录参考。食物种类按完整名称去重，不自动识别菜品中的食材。
